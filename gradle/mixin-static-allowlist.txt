# check-mixin-static-methods.py 的白名单：这些 mixin 里的 @Unique public static 方法
# 由 :common:markSyntheticStaticApi 在编译后打上 ACC_SYNTHETIC，Mixin 的
# checkMethodVisibility 显式放行该标志，且 public+synthetic 不会被改名
# （MixinApplicatorStandard / MixinPreProcessorStandard 两处 javap -c 逐条核对）。
# 真机实测：加了这一步后服务器正常启动，53 条静态门面全部可调（探针 P15a）。
# 没有这一步的地方不要往这里加 —— 直接 @Unique public static 会在 APPLY 阶段 FATAL。
